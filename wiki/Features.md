# 功能一览

## 核心连接与网络诊断

- **多平台支持**：提供 Windows、macOS、Linux 桌面端、Android 应用以及 [OpenWrt 路由端](OpenWrt#下载与架构矩阵)。支持 **Basic** 与 **WinUI** 两种外观主题（旧版 Apple 主题配置会自动迁移为 Basic），适配浅色 / 深色与强调色，桌面应用同时记忆窗口尺寸、位置与最大化状态。
- **无感自动登录**：监听系统网络切换与网卡变化并立即触发检测，配合局域网 IP 检查兜底；Android 端关闭界面后仍可通过前台服务继续检测，并支持开机广播与低频看门狗恢复。
- **网络身份校验**：综合物理网卡、校园网段、Wi-Fi SSID/BSSID 与网关响应确认校园网环境，结合黑白名单降低向未知热点发号的风险。
- **多账号管理**：可保存多个校园网账号并拖动排序，点击账号卡片右侧按钮只控制是否参与自动登录，手动登录与计费查询仍可选用全部账号。
- **认证网卡选择**：Windows、macOS、Linux 可直接在设置页点选指定网卡（自动模式优先校园有线）；Android 自动跟随系统识别到的校园 Wi-Fi。
- **双栈状态**：控制台精简显示 IPv4 / IPv6 连通耗时，更新时间默认只保留 `HH:mm:ss`（跨日时自动带出日期）。网络诊断逐项输出真实耗时并对比系统默认路线与物理网卡直连路线。
- **实时操作与阶段反馈**：登录过程按安全检查、网关确认、凭据提交、联网复核分步反馈并支持提交前取消；进度条平滑展开与收起，并遵循系统“减少动态效果”设置。
- **自适应检测与网络档案**：网络稳定后自动降低后台频率，省电或息屏时减少探测；可按不同 SSID 或有线环境绑定独立账号与策略。
- **流畅滚动与手势**：页面保留滚动位置记忆，从设置页进入子页并返回仍停留在原位；触达顶底边界时触发柔和回弹，同时固定顶栏与底部导航。

## 计费服务与平台维护

- **校园网计费中心**：支持已保存账号或校内“当前登录账号”免密跳转；集中查看余额、流量、在线终端和跨年分页账单（可导出完整 CSV），并提供停复机、套餐预约、消费保护、设备管理与校园卡网费充值（参见[计费与充值](Billing#账户服务)）。
- **用量提醒与托盘快捷操作**：余额或套餐流量低于阈值时推送系统通知；桌面托盘可随时检测、登录、切换首选账号或暂停自动登录 1 小时。
- **VPN 兼容策略**：提供“系统 DNS / 校园网 DNS / 固定地址 / HTTP + IP”四档模式，默认通过固定校园地址与 HTTPS 请求发起认证，不继承系统 HTTP 代理（参见[VPN 兼容策略](Network#vpn-兼容策略)）。
- **统一弹窗菜单与日志**：应用内自定义下拉菜单在桌面与 Android 端保持统一的原位弹性展开 / 收起动效，并贴合滚动与翻页位置；日志保留最近 5 次启动记录，支持按关键字与级别检索及脱敏导出。
- **流量统计与预测**：开启后每分钟采集计费流量，支持分钟至月的尺度缩放、切换增量 / 累计模式、按接口拆分对比与 CSV 导出；结合近期用量估算月底余量（以学校最终账单为准）。
