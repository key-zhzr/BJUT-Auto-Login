# 网络与 VPN

## 选择认证网卡

Windows、macOS 和 Linux 可在设置页直接点选网卡。自动模式优先识别校园有线；指定网卡断开时不会偷偷换用另一张网卡。Android 使用系统识别的校园 Wi-Fi。

同时启用 Wi-Fi 和有线时，认证网卡与系统默认上网网卡可能不同。VPN 能访问互联网，也不代表有线校园网已经认证。

## 查看诊断

诊断会及时显示完成的模块：网络接口、校园路由、校园环境、DNS、互联网与认证网关。网络探测采用 3 秒超时，等待时进度会继续变化。

“互联网连通性”合并显示四项：

| 路径 | IPv4 | IPv6 |
| --- | --- | --- |
| 当前网络（含 VPN） | 系统默认路径 | 系统默认路径 |
| 网卡直连（绕过 VPN） | 所选物理网卡 | 所选物理网卡 |

当前网络在未使用 VPN 时就是系统默认出口。独立探测直接使用公共目标地址，并验证 HTTPS；它不验证任意网站的 DNS 或 HTTP 代理。某个目标超时不代表整个地址族不可用。VPN 禁止直连、网卡未配置 IPv6、目标服务受限时，对应项目也可能未通过。

macOS 有线出现已知 IPv6 配置异常时，诊断页会提供重启适配器入口；重启会短暂中断连接，并可能要求系统管理员授权。

## VPN 兼容策略

| 模式 | 主要用途 |
| --- | --- |
| 系统 DNS | 使用系统解析校园域名 |
| 校园网 DNS | 向对应校园 DNS 查询校园域名 |
| 高兼容 | HTTPS 配合已知校园地址，适合多数 VPN 环境 |
| 最高兼容 | HTTP 配合固定地址；仅在其他模式不可用且网络可信时临时使用 |

认证与计费系统共用兼容设置。lgn 有线的校园 DNS 与公共 Wi-Fi、宿舍环境分别处理。最高兼容会降低传输保护，请阅读[隐私与安全](Privacy)。

## 反馈问题

在诊断页导出诊断包，附上系统、版本、网卡类型以及 VPN 模式。网络切换后旧报告可能失效，请在连接稳定后重新运行诊断。
