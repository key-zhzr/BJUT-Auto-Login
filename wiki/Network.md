# 网络与 VPN

## 选择认证网卡

Windows、macOS 和 Linux 可在设置页直接点选网卡。自动模式优先识别校园有线；指定网卡断开时不会偷偷换用另一张网卡。Android 使用系统识别的校园 Wi-Fi。

同时启用 Wi-Fi 和有线时，认证网卡与系统默认上网网卡可能不同。VPN 能访问互联网，也不代表有线校园网已经认证。

## 查看诊断

诊断按模块依次输出：网络接口、校园路由、校园环境、DNS、互联网与认证网关。单次探测采用 3 秒超时，等待期间持续更新耗时。

“互联网连通性”并排显示两条路径：

| 路径 | IPv4 | IPv6 |
| --- | --- | --- |
| 当前网络（含 VPN） | 系统默认路径 | 系统默认路径 |
| 网卡直连（绕过 VPN） | 所选物理网卡 | 所选物理网卡 |

控制台与诊断页共用“当前网络”的检测结果，每个地址族同时验证多个测试目标，任一响应即判定畅通。当仅某一条探测链路超时或 VPN 拦截直连时，系统会如实标出未通过项和具体原因（例如未分配地址、DNS / TLS 异常或请求超时）。

macOS 有线出现已知 IPv6 配置异常时，诊断页会提示一键重启对应网络适配器；该操作会短暂中断网络并请求系统管理员授权。

## VPN 兼容策略

| 模式 | 主要用途 |
| --- | --- |
| 系统 DNS | 使用系统解析校园域名 |
| 校园网 DNS | 向对应校园 DNS 查询校园域名 |
| 高兼容 | HTTPS 配合已知校园地址，适合多数 VPN 环境 |
| 最高兼容 | HTTP 配合固定地址；仅在其他模式不可用且网络可信时临时使用 |

认证与计费系统共用兼容设置。lgn 有线的校园 DNS 与公共 Wi-Fi、宿舍环境分别处理。最高兼容会降低传输保护，请阅读[隐私与安全](Privacy#网络请求与兼容策略)。

## 反馈问题

在诊断页导出诊断包，附上系统、版本、网卡类型以及 VPN 模式。网络切换后旧报告可能失效，请在连接稳定后重新运行诊断。
