# 本轮改进与验证记录

本轮 App 保持 0.1.6；OpenWrt 两包源码修订为 0.1.6-r19。提交源码不等于发布安装包，本轮不创建版本标签、不部署网站、不更新真实路由器。

## 改动范围

| 范围 | 主要结果 |
| --- | --- |
| 托盘与首次使用 | 区分左右键，左键恢复窗口；图标、标题、提示与菜单可配置；首次使用引导可跳过、续看和重放 |
| 设备流量 | 每分钟读取 jfself 在线设备计数，累计连续增量；两端支持历史、日期与账号筛选、CSV 导出和保守用量预估 |
| 登录顺序 | 可选按新鲜的剩余流量排序；显式账号顺序、停用、失败冷却仍优先适用 |
| 诊断与通知 | 补充系统网络变化事件、质量历史、响应时间分布、预设目标路由跟踪与诊断建议；通知有冷却和恢复条件；PushPlus 测试区分受理与实际送达 |
| App / 路由协作 | 修正端口账号菜单裁切，统计读取缓存；减少重复 RPC 解析；IPv6-only lgn 认证保留接口与目标校验，并展示实际 PD 状态 |
| 安全与迁移 | 集中日志脱敏；备份强度提示与旧格式识别；保留三字符最低要求和现有加密；补充证书、主机名、过期与固定公钥测试 |
| 快捷操作 | 固定的 bjut-al 链接、Android 快速设置磁贴与桌面组件；链接不能携带凭据，登录仍需 App 内确认 |
| 网站与文档 | 正式版与预发布版分开；Android 架构推荐保留不确定性与手动选择；路由包架构矩阵、校验与回退；真实 App 桌面/移动预览、深色模式、指南搜索和锚点 |
| 维护与回归 | 拆分托盘、计费命令、校园服务、流量和诊断模块；加入版本一致性检查、App 与 LuCI 六页浏览器 CI |

## 实际验证

- Rust 库测试：248 通过，4 项忽略；格式检查与 `clippy --all-targets -- -D warnings` 通过。
- 前端类型检查、构建、既有更新检查、计费与协作回归、流量和备份测试通过。
- App 浏览器验收：5 项通过，覆盖三主题动画、macOS / Windows / Android 模拟页面、引导与托盘设置草稿。
- LuCI 浏览器验收通过：桌面与移动尺寸下运行实际六页模块，业务与 UCI 使用模拟接口。
- OpenWrt 宿主完整检查与 12 项上游同步测试通过；新增在线设备共享样例、统计、IPv6 身份与 PD、通知诊断和包检查。
- Android Kotlin、Manifest 和资源编译通过；网站 30 项测试、9 页指南构建与内部链接/锚点检查通过。
- 手动检查网站桌面、手机与深色截图；手机路由下载矩阵不再依赖横向滚动。App、Cargo、Tauri、Android 与两份路由 Makefile 的版本事实源一致。

## 尚需实机验收

- Windows 原生托盘和窗口恢复、Android 磁贴/组件及后台策略。
- macOS 原生托盘左右键与自定义图标；本机已完成原生编译和 Rust 测试，浏览器回归不能代替托盘点击。
- 真实路由器的 IPv6-only 校园认证、PD、mwan3 和持续采样；离线检查没有发送真实认证、充值或通知测试请求。
- 真实设备上的电量、流量和长期性能；减少模拟环境中的重复调用，不代表已测得实机速度提升。

流量历史只记录连续成功采样的增量。首次采样、长时间中断和无法核对的计数重置不补算；按天/月统计与费用预估不是完整计费账单。路由历史定期保存，突然断电可能损失最近一段采样。
