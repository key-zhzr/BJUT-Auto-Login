OpenWrt / ImmortalWrt 路由端

OpenWrt APK / IPK 下载矩阵

官方 SDK 构建：OpenWrt 25.12.5 → APK、24.10.8 → IPK（这里的 APK 是 OpenWrt 新版包格式）。同时提供 bjut-autologin 核心包与 luci-app-bjut-autologin 界面包。

安装前核对：在路由器终端查看 ubus call system board 与 opkg print-architecture / apk --print-arch 确认架构一致；下载后使用 sha256sum -c SHA256SUMS 核对完整性。

常见问题

这是学校官方客户端吗？

不是。BJUT Auto Login 是面向北京工业大学校园网的开源第三方工具，按 MIT 协议开放源代码，与学校信息中心无隶属关系。

开着 VPN 或代理还能用吗？

可以。默认策略固定已知校园地址并通过物理网卡发起认证，不影响日常代理规则。如需调整策略可先运行“网络诊断”，详见VPN 兼容策略。

支持哪些 OpenWrt 路由器？

已在独立路由端仓库维护，支持 MT798x、MT7621、IPQ60xx、x86_64 等 10 类主流平台，提供多上游独立认证和 LuCI 管理页。查看路由端指南。

遇到连接异常怎么反馈最有效？

先在“网络诊断”中等待检测完成，导出脱敏诊断包，然后前往 GitHub 提交 Issue，并附带系统版本与复现步骤。反馈前不要粘贴明文密码或原始配置文件。提交反馈 ↗
