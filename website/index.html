OpenWrt / ImmortalWrt 路由端

OpenWrt APK / IPK 与架构下载矩阵

固定官方 SDK：OpenWrt 25.12.5 → APK、24.10.8 → IPK（非 Android APK）。每项构建同时提供 bjut-autologin 核心包与 luci-app-bjut-autologin 界面包。

校验与元数据回退说明：安装前可在路由器执行 ubus call system board 与 opkg print-architecture / apk --print-arch 核对平台和架构；下载后使用 sha256sum -c SHA256SUMS 校验完整性。官网仅展示已验证的元数据与真实 SHA-256，不编造未发布包或校验值。

构建清单 builds.json ↗校验文件 SHA256SUMS ↗路由端 Releases ↗Actions 编译工作流 ↗查看路由端指南 ↗

你可能想知道

这是学校官方应用吗？

不是。BJUT Auto Login 是开源第三方工具，由项目维护者独立开发，与学校官方应用无隶属关系。

可以与 VPN 一起使用吗？

支持多档 VPN 兼容策略。建议先使用默认设置，遇到问题时在网络诊断中查看当前网络和网卡直连的结果。查看使用说明。

有 OpenWrt 路由器版本吗？

路由端已在独立仓库维护，提供多上游自动认证、LuCI 界面与 App 局域网协作。查看路由端说明。

遇到问题如何反馈？

先运行网络诊断，再到 GitHub 提交问题。请附上系统版本、应用版本及脱敏诊断信息，不要公开账号密码。提交反馈 ↗
